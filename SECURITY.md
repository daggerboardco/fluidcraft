# Security Policy

## Supported Versions

Fluidcraft is in early development. Only the latest release is supported for
security issues until a stable version is tagged.

| Version | Supported |
|---|---|
| 0.1.x (current) | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than
opening a public issue.

- Email: (not yet configured — open a GitHub issue marked private if the repo
  is mirrored, or contact the maintainers directly.)
- Include: a description of the vulnerability, steps to reproduce, and severity.

We aim to acknowledge reports promptly and work with you on a fix.
